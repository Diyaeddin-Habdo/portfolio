# Diyaeddin Habdo — Software Engineer Portfolio

Personal portfolio website presenting my professional experience, selected projects and engineering stack.

**Live website:** [diyaeddin-habdo.github.io/portfolio](https://diyaeddin-habdo.github.io/portfolio/)

## Tech stack

- React 19
- Vite
- Tailwind CSS 4
- Framer Motion
- React Icons

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The site is configured for the `/portfolio/` GitHub Pages base path.
